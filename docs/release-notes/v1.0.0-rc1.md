# animaEngine 1.0.0-rc1 — the first 1.0 release candidate

This is a **release candidate**, not the final 1.0. It exists to bake:
run it on real desktops for a couple of weeks and report anything that
breaks before `1.0.0` is tagged. Only RC-blocker fixes land between now
and the release.

## What changed since 0.9.0

The headline is parity and hardening, not new toys — the freeze held.

- **The native Wayland path caught up to X11.** With
  `ANIMA_USE_WAYLAND_NATIVE=1` on a wlroots compositor, the asset
  library, the right-click context menu, and per-monitor distribution
  (a sprite-only layer surface per output) now all work. Exercised
  against a real headless `sway`, output hotplug included.
- **GNOME got usable.** GNOME on Wayland — Ubuntu's and Fedora's
  default — runs through XWayland, where Mutter kept sinking the overlay
  behind focused windows and occasionally swallowing click-throughs.
  The overlay now re-asserts always-on-top and self-heals its
  click-through region, so characters stay on top and clicks reach the
  windows beneath them. One honest limit remains: a click can't pass
  through to a *native-Wayland* window underneath — that's the XWayland
  boundary, tracked for after 1.0.
- **The settings panel is lighter** — icon-only tabs and a frosted,
  semi-transparent panel.
- **A pile of fixes** found by building and running from source on Kali,
  Fedora, Arch, and Alpine: a HiDPI / fractional-scale bug that pushed
  the ⚙ toggle button off-screen, multi-monitor crashes on the Wayland
  path, atomic crash snapshots, a `memmap2` security advisory, and the
  build-dependency gaps each distro surfaced (`pkg-config`,
  `libxkbcommon-x11-dev`, the Alpine musl `-crt-static` flag).

## The 1.x promise

From 1.0 onward your `config.toml`, the `org.animaengine.Anima` D-Bus
methods, the CLI flags, and the documented environment variables are
stable across the whole 1.x line — see
[the stability policy](https://github.com/Alexandru2984/animaEngine/blob/main/docs/stability-policy.md).

## How to help the bake

Run it on your actual desktop. File an issue if anything regresses from
0.9.0, with your distro, session (X11 / Wayland + which compositor), and
the `RUST_LOG=anima_engine=info` output up to the problem.
