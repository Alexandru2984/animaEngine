# animaEngine 0.5.3 — re-audit follow-up

After 0.5.2 closed the original 0.5.0 audit findings, the codebase
got a second pass. Verdict: zero regressions introduced by the
0.5.1 / 0.5.2 patches, no new critical or high. Two medium and
four low findings — all addressed here. Take this update at your
leisure; it's incremental hardening, not a hot patch.

## What's fixed in 0.5.3

### G.1 — finish the M4 redaction sweep

The 0.5.2 pass covered the drop / library / Wayland code paths but
left 11 more info-level traces leaking absolute paths into journald:
`config.rs` (load + save), `main.rs` startup banner,
`scene.rs::add_entity_from_path` instrument macro, every `loader.rs`
info! for the seven asset types, the PNG sequence warnings on
file-count + decoded-bytes truncation, plus the per-frame "failed
to load PNG" warning. All now go through `drop_validate::redact_path`;
the full path remains available at `RUST_LOG=anima_engine=debug`.

### G.2 — SAFETY comments on libc::getuid blocks

The M3 fix in 0.5.2 added `unsafe { libc::getuid() }` calls at three
sites without `// SAFETY:` comments. The block was sound (POSIX
guarantees no failure, no side effects), but the rest of the
codebase consistently documents unsafe (`src/wayland/layer_window.rs:225`
is the model). Added the comments for uniformity.

### G.3 — extend control-char filter to Unicode Cf category

The F.7 filter only caught `is_control()` (Cc). Re-audit flagged
that Cf characters slip through: zero-width chars (U+200B–U+200F,
U+FEFF), bidi-override (U+202A–U+202E), invisible operators
(U+2060–U+206F), soft hyphen (U+00AD). A simulated-keystroke
attacker could plant invisible or display-reversing strings in
egui `TextEdit` widgets (preset names, library tags, search
field). Filter extended via a new `is_unsafe_text_char` predicate.

### G.4 — PNG sequence decode peak memory

The previous loader collected all decoded frames into a `Vec`
before applying `MAX_DECODED_ASSET_BYTES`. With `MAX_SEQUENCE_FILES
= 1 000` and 4K RGBA (33 MB/frame), transient peak memory reached
~33 GB before the post-hoc cap. Reworked to use an
`AtomicUsize` running total + `AtomicBool` early-bail flag inside
the `par_iter` worker so each thread reserves its slice of the
budget atomically and discards over-cap frames. The kept prefix
preserves source order via `par_iter().collect()`'s ordering
guarantee.

### G.5 — TextEdit `char_limit(256)` on search boxes

Library tab search and Ctrl+K command palette `TextEdit::singleline`
widgets gain `.char_limit(256)`. Caps an otherwise unbounded buffer
if a programmatic clipboard inject pastes a huge string.

### G.6 — D-Bus try_send overflow log

`WaylandActivationService` methods used `let _ = self.tx.try_send(...)`
with no telemetry on overflow drop. A deluged operator had no way
to see why their `gdbus` calls weren't taking effect. Centralised
through a `dispatch` helper that logs at `debug` (not `info`/`warn`
— that would let an attacker amplify their flood into our log
volume).

### G.7 — asset library scanner canonical-root check

The M2 fix hardened "Add to scene" but the scanner itself still
walked symlinks naively: a `~/library/external → /etc/` symlink
surfaced `/etc/` files in the library UI, even though
`resolve_library_asset` would reject them at decode time. Reworked
`scan` to canonicalise the root once and `walk` to canonicalise
each candidate, dropping entries whose canonical form escapes the
canonical root. Listing leak closed.

257 pass (231 lib + 25 integration + 1 demo). `cargo clippy

## Upgrade notes

`config.toml` files saved by any prior version decode unchanged.
Observable user-facing changes:

- Drag-drop / library "Add to scene" / asset load log lines show
  the file name only at `RUST_LOG=info`. Set
  `RUST_LOG=anima_engine=debug` to see full paths when bug-hunting.
- Library scan ignores symlinks that point outside the library
  root. Real-world impact: zero unless your library had escape
  symlinks.
- Search boxes refuse text past 256 characters. Real-world impact:
  zero unless you paste a wall of text into the search field.

```bash
# Debian / Ubuntu
sudo apt install ./anima-engine_0.5.3-1_amd64.deb

# AppImage
chmod +x animaEngine-0.5.3-x86_64.AppImage
./animaEngine-0.5.3-x86_64.AppImage
```

All 0.5.0 audit findings closed (3 critical + 4 high in 0.5.1,
4 medium in 0.5.2). The 0.5.2 re-audit's 2 medium + 4 low findings
closed in this release. The remaining informational items from the
