# animaEngine 0.4.0 — UX completion

Faza D — ten sub-phases focused on the surfaces a user actually
touches. The 0.3.x line landed the engine plumbing (multi-monitor,
asset library, behaviour expansion, sprite groups, packaging fix);
0.4 is about making the *daily-use* layer feel polished, observable,
and self-explanatory.

## Highlights

### Rebindable keyboard map (D.1)

Every action animaEngine dispatches now lives in `src/keybindings.rs`
as one variant of `Action` (27 user-facing actions + 1 dev
affordance). The new **Keybindings** tab in the settings sidebar
shows the live chord table:

- Per row: action label, current chord chips, **+ Record** button,
  per-row **Reset to default** affordance.
- Click **Record** → press the next chord — that becomes the new
  binding. `Esc` cancels recording.
- Conflicts colour the offending chord yellow and list the colliding
  action under the row; the binding still works but the user is
  flagged.
- Footer **Reset all to defaults** restores the entire table.

Bindings persist in `config.toml` under `[keybindings.map]`. Chord
strings round-trip through `KeyChord::FromStr` — `"Ctrl+Shift+A"`,
`"Esc"`, `"ArrowUp"`, `"Ctrl+M"`, etc. — so hand-editing the file
works. New configs decode pre-0.4 files unchanged; the default
chord set matches the hard-coded 0.3 shortcuts exactly, so muscle
memory carries over.

### Persistent inspector + preset-gallery state (D.2)

The four inspector sections (Position / Appearance / Animation /
Behavior) and the Scene tab's preset gallery now remember their
open/closed flag across sessions, persisted under
`[collapse_state]`. Defaults match the previous hard-coded
`default_open` heuristic, so an upgrading user sees no visual
shuffle on the first run — only the *next* toggle starts to stick.

### Runtime AccessKit toggle (D.3)

`Appearance → Accessibility → Generate AccessKit tree updates` —
checkbox flips the egui runtime gate
(`Context::enable_accesskit()` / `disable_accesskit()`) without a
restart. The AT-SPI socket itself stays alive; what's gated is
tree-update generation, which is the dominant cost. Default `true`
so screen-reader users keep working out of the box.

### Locale review pipeline + 9 audit reports (D.4)

`docs/i18n-pipeline.md` documents the contract for adding new
strings:

1. English form in `en.ftl`.
2. Same key in every other locale — real translation if available,
   placeholder English with a comment marker if not.
3. Parity test (`every-locale-covers-every-en-key`) gates the build.
4. `t()` lookups at the call site; never inline literal strings in
   Rust code.

Per-locale audits at `docs/locale-audit/{ro,de,es,fr,it,nl,pl,pt-BR,ja}.md`
list placeholder strings, glossary anchors, and suspected register
issues. AI confidence varies by language (`de`/`es`/`fr`/`it`/`pt-BR`:
medium-high; `nl`: medium; `pl`/`ja`: low). `.github/ISSUE_TEMPLATE/locale-review.md`
makes review requests structured.

### Persistent warning banners + toast wiring (D.5)

The new `Warning` enum (`GlobalHotkeysUnavailable`,
`HotReloadDisconnected`) renders session-lifetime banners at the
top of the settings panel — distinct from toasts because the
underlying condition is persistent. If `XGrabKey` couldn't grab
the global chord set (typical on native Wayland sessions), the
user sees a yellow banner explaining that the tray + ⚙ button
still work. If the hot-reload worker crashes silently, the user
finally hears about it instead of wondering why their config edit
didn't apply.

Toast coverage filled in at two paths that were tracing-only
before: duplicate via D-key, palette preset append failure.

### Live perf overlay (D.6)

Default chord: `Ctrl+Shift+\`` (rebindable through the Keybindings
tab). Toggles a floating window anchored top-right of the
settings panel showing:

- **FPS** — derived from the 60-frame rolling average of total
  frame time.
- **avg / p95** total frame time in milliseconds.
- **Per-category averages** for `scene_update`, `egui_paint`,
  `wgpu_submit`, `present`, `idle` — 60-frame rolling window.
- **RSS** in MiB (Linux: `/proc/self/status`).
- **Sparkline** of the last 120 frame totals, with a 16.7 ms
  reference line for 60 fps context.
- **Export snapshot** — writes a chrome-tracing JSON to
  `~/.cache/animaEngine/perf-<nanos>.json`. Open in
  `chrome://tracing` or [Perfetto](https://ui.perfetto.dev/).

The sampler always runs (one `Instant::now()` per frame, well below
noise); the overlay is what's gated.

### Onboarding 2.0 (D.7)

The progressive-tooltip concept from Faza A is preserved. Added:

- **"What's new in 0.4"** highlight panel anchored by
  `WHATS_NEW_VERSION = "0.4.0"` — one-shot per minor-version bump,
  dismissed by clicking ✕, stamps the version into
  `[global].last_seen_whats_new` so the next session skips it.
- Two new hint sites — one under the Keybindings tab header
  explaining the record / remove UX, one at the bottom of
  Appearance pointing at the perf-overlay chord.
- `Appearance → Reset onboarding hints` button so users can retake
  the tour.

### Empty-state CTAs (D.8)

Empty states no longer end in a dead-end hint. The Scene-tab empty
card has a **Browse presets** button that toggles the preset
gallery open. The Library no-asset-root + empty-index cards have a
**Copy path to clipboard** button so users paste the documented
assets path into a file manager / terminal without typing.

### Consistency pass (D.9)

- Inspector section headers (Position / Appearance / Animation /
  Behavior) wired through `t()` against the i18n keys that already
  existed but were never hooked — non-English locales see them in
  their language for the first time.
- Dead i18n keys (`appearance-keyboard-header`,
  `appearance-keyboard-note`) removed from all 10 locale files.
- Tooltip pass on the buttons added in D.1-D.8: perf-overlay export
  button now hovers a description of the snapshot path + format;
  Reset onboarding button hovers a hint explaining what gets reset.

## Upgrade notes

`config.toml` files saved by 0.3.x decode unchanged — every new
field carries `#[serde(default)]`. The first edit-mode session
after upgrade shows the "What's new in 0.4" panel; dismissing it
stamps the version into `[global].last_seen_whats_new` so the next
session skips the panel. The previously hard-coded chord set
survives intact as the default `[keybindings.map]` — muscle memory
is preserved without action.

```bash
# Debian / Ubuntu
sudo apt install ./anima-engine_0.4.0-1_amd64.deb

# AppImage
chmod +x animaEngine-0.4.0-x86_64.AppImage
./animaEngine-0.4.0-x86_64.AppImage
```

## Test suite

236 tests pass (210 lib + 25 integration + 1 demo). `cargo clippy
--all-targets -- -D warnings` is clean.

## What's next — 0.5 / Faza E

Platform reach:

- Native Wayland complete — `wlr-layer-shell` overlay with egui +
  drag-drop reaching parity with the X11 path.
- macOS port — wgpu Metal backend already builds; window
  attribution + AT-SPI replacement (NSAccessibility) + .app
  packaging.
- FreeBSD support — most of Linux carries over; the missing piece
  is the X11 input-shape XCB call and packaging via `make pkg`.
- Fuzzing harness — `cargo fuzz` targets for asset decoders.

The 0.4 series may see one or more patch releases for native-speaker
locale fixes (D.4 audit findings) before 0.5 starts.
