# animaEngine 1.4.0

Screen readers can read animaEngine — for the first time — and two
smaller additions.

## What you'll notice

- **Screen readers.** Orca and other screen readers that use AT-SPI can
  read and operate the settings panel, the command palette and the
  tour, on X11 and on native Wayland, and follow the focus as Tab moves
  it. This is new, not repaired: the documentation has said since 0.2
  that screen readers worked, but the bridge it described was never
  connected, and no screen reader ever saw anything. Buttons that are
  only an icon now have names a reader can say ("Exit edit mode",
  "Delete: Ghost Demo"), fields and lists are named after their
  labels, and icons are left out of what is read.
- **Add file…** in the Scene tab opens your desktop's file chooser and
  adds the files you pick as characters. No dragging needed — and in
  the Flatpak, a way to files outside Pictures and Downloads, which a
  drop cannot reach.
- **Ctrl+K runs any action.** The command palette lists every action
  that has a shortcut, with the shortcut beside it, and runs the one you
  pick. The ones that act on the selected character are listed while
  one is selected.

## Fixed

- In the command palette, the arrow keys moved the highlight but Enter
  still picked the first row.
- Keys typed into the command palette could run shortcuts once its
  search box had lost the focus, as it does after Enter on a search that
  matched nothing: Escape also left edit mode, and Q would have quit.
- The command palette no longer reopens filtered by the last search.
- A combo box's list stayed open when an option was chosen from the
  keyboard or by a screen reader. It closes now.
- Escape with a list or the right-click menu open also left edit mode.
  It closes only the list or the menu now.

## Changed

- **Appearance → Generate AccessKit tree updates**, turned off, now
  shows a screen reader an empty window instead of doing nothing.

## Compatibility

Additive: no change to the config, the D-Bus methods, the CLI or the
file locations. See [stability-policy.md](../stability-policy.md).

## Known gaps in verification

Screen readers were checked on a headless compositor, on both backends,
with an AT-SPI client built on the library Orca itself uses: the tree
and its names, pressing and focusing through AT-SPI, and the focus
events a reader follows — not yet with Orca, in the Flatpak, or on real
hardware. "Add file…" was checked against a stand-in for the XDG
portal, not a real desktop's dialog, and not in the Flatpak, where the
point is the document portal granting the picked files. Both are
Linux/BSD only; the Windows build has neither yet. The new text is
machine-translated in nine of the ten languages.
`docs/runtime-findings.md` has the detail (R52, R53).

The full list is in [CHANGELOG.md](../../CHANGELOG.md).
