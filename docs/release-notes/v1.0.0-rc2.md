# animaEngine 1.0.0-rc2 — bake fixes

Second release candidate. rc1's bake did its job: a post-release audit
of the shipped product — live probes of the error paths, a memory soak,
and verification of the published artifacts themselves — found four
real defects. rc2 is those fixes and nothing else.

## Fixed since rc1

- **Single-instance actually works now.** On rc1, launching the app
  while it was already running silently started a *second* full overlay
  (two tray icons, two processes writing the same config) instead of
  raising the first — a zbus 5 API behavior (`Err(NameTaken)` in place
  of the `Exists` reply) made the "already running" branch unreachable.
  A second launch now hands off in about 0.1s and the running instance
  raises its window.
- **A corrupted `config.toml` can't destroy your scene anymore.** If
  the file exists but fails to parse (say, a typo from a hand edit),
  rc1 overwrote it with defaults — losing everything in it. The
  unreadable original is now backed up to `config.toml.bak-corrupt`
  before defaults are written, matching the backup discipline the
  schema migrations already had.
- **Unknown command-line flags are rejected.** `anima-engine --recovr`
  (note the typo) used to silently launch the overlay; it now prints
  the offending flag plus usage and exits with status 2.
- **`sha256sum -c` now verifies downloads.** GitHub renames `~` to `.`
  in uploaded asset filenames, so rc1's SHA256SUMS listed a `.deb` name
  that didn't match the published asset (the content hash was correct —
  name-only mismatch). Artifacts are renamed before checksumming from
  this tag on.

## Memory, while we were in there

A 9-minute 16-entity soak on real hardware came back **flat**:
steady-state RSS slope 0.28 KiB/min (threshold 512), GPU texture count
pinned at exactly one per entity, no growth anywhere. The full report
method is `scripts/soak.sh`.

## How to help the bake

Same as rc1: run it on your actual desktop, and file an issue if
anything regresses — distro, session type (X11 / Wayland + compositor),
and `RUST_LOG=anima_engine=info` output up to the problem.
