# animaEngine 1.3.0

Two features that were genuinely missing — not only undocumented.

## What you'll notice

- **Characters on every monitor can be edited.** With more than one
  monitor, the characters on the others can now be selected, dragged,
  poked and dropped onto, and dragged from one screen to another. The
  settings panel stays on the main monitor; a right-click on a character
  elsewhere opens its menu at the main monitor's nearest edge. On the
  native Wayland backend those characters used to be drawn and could not
  be touched at all; on X11, a file dropped on another monitor was
  ignored.
- **Input methods on native Wayland.** fcitx5, ibus and the other input
  methods for Chinese, Japanese and Korean now work on the native
  Wayland backend, which until now had none: the text being composed
  shows in the field, the candidate window follows the caret, and the
  committed text replaces it. The default X11 path already had them.
- **CJK text is drawn.** On both backends, the CJK font is now loaded the
  first time an input method composes Chinese, Japanese or Korean text —
  before, that text arrived as a row of empty boxes unless the whole
  interface was in Japanese.

## Fixed

- **Native Wayland could leave a monitor empty.** Launched while a
  monitor other than the first was focused, the overlay covered one
  monitor twice and another not at all, and the characters on it were
  invisible.
- **A right-click menu could close by itself** when it was drawn away
  from the pointer — for a character near a screen edge, or on another
  monitor. On X11 it was also misplaced when the main monitor is not at
  the top-left of the desktop.

## Compatibility

Additive: no change to the config, the D-Bus methods, the CLI or the
file locations. See [stability-policy.md](../stability-policy.md).

## Known gaps in verification

Both features were checked on a headless compositor with two outputs and
a virtual pointer and keyboard, on both backends, and the input methods
with a minimal test input method written for it — not yet with fcitx5 or
ibus themselves, on real multi-monitor hardware, or on compositors other
than sway. The "What's new" text is machine-translated in nine of the
ten languages. `docs/runtime-findings.md` has the detail (R50, R51).

The full list is in [CHANGELOG.md](../../CHANGELOG.md).
