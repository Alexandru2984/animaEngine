# v1.0 — The contract (Faza X)

Umbrella: [docs/roadmap-1.0.md](../roadmap-1.0.md). Procedural
phase: no feature code, only verification and paperwork. One
sub-phase = one commit, standard gate.

1.0 is a promise, made checkable:

1. A `config.toml` written by any 1.x loads in every later 1.x.
2. Nothing visible in the UI is half-built; no shipped code path
   carries a "lands later" comment.
3. Global shortcuts work natively on GNOME, KDE and wlroots.
4. A documented multi-day soak shows flat memory.
5. Installable from GitHub Releases, Flathub and AUR.

## X.0 — RC1 (S)

## X.1 — The stability policy (S) — DONE 2026-06-16

- *As shipped:* `docs/stability-policy.md` written from the code —
  **guaranteed across 1.x**: config schema (with the W.0 migration +
  backup mechanism), the five `com.animaengine.Anima` D-Bus methods,
  the `--help`/`--recover` CLI flags, the seven `asset_type` values +
  the drop-extension allowlist, and the XDG file locations;
  **not guaranteed**: internal crate API, log format, perf-overlay
  numbers, undocumented (`ANIMA_SOAK_*`) env vars. Deprecation runway
  documented (announce → one-minor runtime warn → remove no earlier
  than 2.0; config keys migrate rather than break). Framed as effective
  *with 1.0.0* (0.x had no guarantee). Linked from README and SECURITY.md;
  the SECURITY supported-versions table was stale at 0.5.x → updated to
  0.9.x. Docs-only.

## Failure mode

If the bake finds a contract violation that can't be fixed inside
two weeks, RC2 restarts the clock. 1.0 ships when the checklist is
green, not on a date.
