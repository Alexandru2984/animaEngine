# v0.7 — Content & feature completion (Faza U)

Umbrella: [docs/roadmap-1.0.md](../roadmap-1.0.md). Rolling-wave
detail level: firm scope, sketched design — U.1's data model gets its
final design review at phase start, after 0.6's multi-window dust
settles. One sub-phase = one commit, standard gate.

Theme: things users *see*. Shimeji pack import is the user magnet
(thousands of community packs, no maintained Linux engine); it forces
the one honest engine gap — multi-state animations — and the release
closes every "lands in C.x" comment left in the tree.

## U.0 — Shimeji format research doc (S)

- `docs/shimeji-import.md`: pack anatomy (`img/shime1.png…N.png`,
  `conf/actions.xml`, `conf/behaviors.xml`), the subset we map
  (stay/walk/fall/drag states), what we drop and why (window-edge
  climbing needs window-geometry awareness — post-1.0; multi-mascot
  interactions — out of scope).
- Security pre-analysis: XML via `quick-xml` (no DTD → no entity
  expansion), depth/size caps, image count/size caps reusing the
  asset pipeline's existing constants, paths canonicalised under the
  pack root (`resolve_library_asset` pattern).
- License note: imported packs are user content; we never bundle any.

## U.1 — Multi-state animation model (L) — load-bearing wall

- `AnimationSet`: `HashMap<StateId, Sequence>` where `StateId ∈
  {Idle, Walk, Fall, Drag}` (closed enum, not strings — exhaustive
  match keeps behavior wiring honest); each `Sequence` = frames +
  fps + optional per-frame delays.
- Config schema additive: `[characters.animations.idle]` tables;
  legacy single-sequence configs deserialize into a one-state set
  (serde custom). **No migration needed** — old shape stays valid
  (the 0.9 versioning formalises this).
- Cache format: one cache entry per (asset, state) using the 0.5.5
  fingerprint — format version bump, one-time rebuild.
- Aggregate memory budget counts all states.

Design review checkpoint at phase start: egui texture path and
`texture_dirty` semantics under state switches.

## U.2 — Behavior ↔ state wiring (M)

- Behavior tick reports desired `StateId` + facing; `Animation`
  switches sequence on state change (frame index reset, clock
  resync); horizontal flip for walk direction (vertex UV flip — no
  texture duplication).
- Fallback rules: missing state → `Idle` sequence (never panic).

## U.3 — Shimeji importer core (L)

- `src/shimeji/mod.rs`: pure `fn import_pack(root: &Path) ->
  Result<Vec<CharacterConfig>, ImportReport>` — parse, map actions →
  states, copy/normalise images into the asset library root,
  generate configs with animation sets.
- Golden-file tests against 2–3 reference packs (self-made minimal
  fixtures in `tests/fixtures/` — small, licensed, ours).
- Every cap from U.0 enforced with specific error strings.

## U.4 — Import UX (M)

- Library tab: "Import Shimeji pack" — drop a folder onto the
  overlay or paste a path (no new file-dialog dependency).
- Progress + per-pack report toast; partial imports surface what was
  skipped and why.

## U.5 — Library thumbnails (M) — closes C.5

- First decoded frame → 64 px PNG under the existing
  `thumbs/` cache dir (paths shipped 0.3, never populated); decode
  off-thread via the drop-worker pattern (bounded concurrency);
  egui texture cache with LRU eviction; cache key = 0.5.5
  fingerprint.

## U.6 — Library grid v2 (S)

- Thumbnail grid replaces text rows; fallback glyph for
  un-decodables; keyboard navigation + AccessKit labels preserved.

## U.7 — Group composition in renderer (M) — closes C.9

- `GroupConfig.offset_x/y` + `scale` composed at draw-list build;
  hit-testing on composed bounds; inspector shows effective
  transform with a "from group X" hint.

## U.8 — Release 0.7.0 (S)

- Audit focus: XML parsing surface, importer path traversal, state
  cache deserialization.
- Ceremony as standard. README gains the Shimeji walkthrough.

## Risks

| Risk | Mitigation |
|------|-----------|
| U.1 schema churn breaks configs | Additive-only schema; old shape stays first-class; round-trip tests old→new→old. |
| Shimeji packs in the wild are messier than the spec | Importer is total: every malformed input → specific skip reason in the report, never a crash; fixtures grow with each bug report. |
| Thumbnail decode floods slow disks | Bounded worker pool + only-visible-rows decode + cache. |
