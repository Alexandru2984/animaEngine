プライバシー

アプリは何も収集しません。animaEngine はネットワークに一切接続しません。テレメトリーも、クラッシュレポートの送信も、アップデートの確認も、アカウントも、広告もありません。あなたやコンピューター、画面の内容についての情報が外に出ることはありません。

アプリがコンピューターに保存するもの

  • 設定とシーン。ユーザーの設定フォルダー(Linux では ~/.config/animaengine、Windows では %APPDATA%\animaEngine)に保存されます。
  • 追加した画像はアセットライブラリに、その読み込み済みのコピーはキャッシュフォルダーに保存され、読み込みが速くなります。
  • クラッシュの後には、直前のシーンのコピー(anima-engine --recover 用)。

すべてはあなたのコンピューターの、あなたのユーザーのフォルダーに残ります。アンインストールしても再インストールに備えて残るので、消したいときはそれらのフォルダーを削除してください。場所はよくある質問にあります。

診断レポート

外観 → このアプリについて → 診断レポートをコピー を押すと、短いテキストがクリップボードに入ります。アプリのバージョン、システムの名前、グラフィックカード、アプリの最近の警告で、ファイルのパスは決して含まれません。アプリはこれをどこにも送りません。あなたが貼り付けた場所にだけ届きます。

このウェブサイト

このサイトは Cookie を使わず、アクセス解析やスクリプトも動かさず、他のサイトから何も読み込みません。配信は GitHub Pages が行い、ほかのウェブサーバーと同じく、リクエストのたびにあなたの IP アドレスを受け取ります。GitHub のプライバシーに関する声明をご覧ください。ダウンロードも GitHub のリリースページから、同じ声明のもとで提供されます。
